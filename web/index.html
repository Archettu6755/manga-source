Suwatte

支持 Suwatte 7.0.0 及更新版本。提供拷贝漫画、Komiic 和 MangaDex。

Komiic 以繁体中文为主。MangaDex 仅收录日漫，默认英文译文，也可选择日语章节。

打开源列表与安装页面

在阅读器添加 https://archettu6755.github.io/manga-source/suwatte/

Venera

提供拷贝漫画、Komiic 和 MangaDex，按原版 Venera 1.6.3 的 JavaScript 源接口开发。

打开安装页面 · 源列表 JSON

源仓库地址：https://archettu6755.github.io/manga-source/venera/index.json

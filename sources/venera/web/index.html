杕的自用漫画源 · Venera

支持原版 Venera 1.6.3 和沿用原版 JavaScript 源接口的衍生版。

在漫画源管理中修改源仓库地址，填入下面的 JSON 地址，再安装所需源：

https://archettu6755.github.io/manga-source/venera/index.json

打开源列表

也可以通过链接单独添加源：

  • 拷贝漫画：中文漫画、完整浏览目录、专题和男女频排行榜。
  • Komiic：以繁体中文为主，支持卷与章节筛选及登录。
  • MangaDex（日漫）：只收录原始语言为日语的作品，默认英文译文，可切换日语章节。

使用独立的源 ID，可与其他仓库的同站源并存。账号登录由 Venera 原生账号功能管理；应用会保存账号信息用于重新登录。

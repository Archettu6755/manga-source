首次加载目录后重置筛选器，使阅读器重新获取选项。目录缓存存放在对应图源的偏好数据中。加载空目录和网站明确限制的分页时保留入口及提示。首页推荐以合并漫画卡片列表呈现，专题保留在独立筛选入口。

Komiic 的「访问入口」可选 `komiic.com` 或大陆入口 `komiic.cc`，源 ID 保持 `790675500000000002`。两个入口分别登录，目录缓存也按入口保存。切换后刷新作品与目录，再重置筛选器获取当前入口的选项。

CopyManga 作品列表每页 50 条，推荐／上新每页 60 条，专题索引每页 6 条。榜单保持官网每个榜单的原始顺序。Komiic 漫画列表每页 30 条，作者／原作／角色目录按官网分页加载；原作和角色按关联 ID 恢复作品顺序。MangaDex 书单先按原顺序恢复作品，再过滤为可读日漫；公开 API 的 10,000 条分页上限仍适用。

账号收藏、网站阅读记录、评论、投稿及网站设置未适配；书架、历史和下载由 Tachimanga 管理。

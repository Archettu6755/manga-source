杕的自用漫画源 · Tachimanga

适用于 App Store 版 Tachimanga。一个扩展包含拷贝漫画、Komiic 和 MangaDex（日漫）。

在「浏览 → 扩展 → ＋ → 扩展仓库」中添加：

https://archettu6755.github.io/manga-source/tachimanga/index.min.json

刷新扩展列表，安装「杕的自用漫画源」。图源语言筛选需要启用中文和多语言（Multi）。

下载扩展 APK · 扩展列表

  • 拷贝漫画：大陆／海外线路、官网与 API 设置、网页／App 搜索和登录。
  • Komiic：繁体中文漫画、卷／章节选择、题材、标签、作者、原作、角色和推荐入口。
  • MangaDex：原始语言为日语的日本漫画，不默认译文语言，支持语言筛选、标签筛选和省流图片。

更多入口位于图源的筛选器。专题、题材、作者等目录首次使用时，选择对应入口并搜索以加载目录，再重置筛选器选择条目。

拷贝漫画在中国大陆直连时，先使用「大陆入口＋大陆线路」，API 域名留空。修改线路后刷新漫画目录，再重新打开章节。
